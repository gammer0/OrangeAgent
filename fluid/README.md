# 二维液态水粒子仿真（PBF / 位置约束粒子法）

用 pygame 演示二维液态水：粒子受重力下落，靠**密度约束**维持不可压缩性，
可以自由加液体、画固体障碍。约束全部在**位置层面**求解，速度由位置差反推——
不做"给速度加压力加速度"这类会破坏不可压缩性的简化。

```
fluid/
├── main.py      # pygame 主循环：事件、固定步长、渲染（唯一 import pygame 的文件）
├── core.py      # 纯物理：ParticleSystem，不依赖 pygame，可无头驱动
├── config.py    # 常量表：半径、重力、迭代次数、阻尼、颜色
└── README.md    # 本文件
```

---

## 一、启动方式

### 依赖

- Python 3.9+
- pygame（2.x）

```bash
python -m pip install pygame
```

`main.py` 是**唯一** import pygame 的模块；`core.py` 与 `config.py` 完全无窗口依赖，
因此物理层可以被测试工具直接实例化、直接 `step()`。

### 正常运行（打开窗口）

```bash
python fluid/main.py
```

窗口尺寸 = `WORLD_WIDTH + PANEL_WIDTH` × `WORLD_HEIGHT` = **1120 × 600**：
左侧 900×600 是世界区，右侧 220px 是信息面板。

若当前目录已在 `fluid/` 内，也可以用：

```bash
python main.py
```

启动即加载默认场景：两块台阶、底部托盘、上方两团水（共 620 个粒子）。
缺少 pygame 时程序会打印 `缺少依赖 pygame，请先执行：python -m pip install pygame`
并以退出码 2 结束，而不是抛栈。

### 无头运行 / 自检

```bash
# dummy 视频驱动，跑满 120 帧后自动退出并打印摘要
python fluid/main.py --headless --frames 120

# 额外走一遍"加液体 / 画固体"的代码路径（无需鼠标）
python fluid/main.py --headless --frames 200 --auto
```

| 参数 | 含义 |
|---|---|
| `--headless` | 使用 SDL dummy 视频/音频驱动，不建真实窗口 |
| `--frames N` | 跑满 N 帧后退出（0 = 一直运行），退出时打印摘要 |
| `--auto` | 自检模式：第 5 帧画一块固体，前 40 帧持续落水 |

退出摘要形如：

```
退出摘要：{'frames': 200, 'particles': 830, 'solids': 3, 'mass': 830.0, 'kinetic_energy': 41.7, 'paused': False}
```

`mass` 应恒等于粒子数（单位质量 1.0，见「质量守恒」）。

### 单独驱动物理层

```python
from fluid.core import ParticleSystem

s = ParticleSystem(900, 600)
print(s.rho0)                       # 静止密度 ≈ 6.9026e-03
s.add_water(400, 100, 24.0, 200)    # 以 (400,100) 为中心、24px 为散布半径加 200 个粒子
s.add_solid((100, 400, 300, 14))    # 轴对齐矩形 (x, y, w, h)
for _ in range(500):
    s.step(1.0 / 60.0)
print(s.total_mass, s.kinetic_energy, s.count)
```

只读属性：`particles`（`[(x, y, vx, vy), ...]` 副本）、`solids`、`count`、
`total_mass`、`kinetic_energy`、`rho0`、`width`、`height`。外部无法就地篡改内部状态。

| 操作 | 效果 |
|---|---|
| **左键按下 / 拖拽** | 在鼠标处落水；按住时每隔 0.035 秒落一批（画刷半径 24，每批 6 粒） |
| **右键按下并拖拽 → 抬起** | 按下点到抬起点之间画一个固体矩形（宽或高 < 4px 时忽略并提示） |
| `C` | 清空全部液体 |
| `X` | 清空全部固体 |
| `Space` | 暂停 / 继续物理推进（渲染与交互仍然响应） |
| `R` | 重置为默认场景（清空后重建台阶、托盘与两团水） |
| `Esc` 或点关闭按钮 | 退出 |

补充约定：

- 只有落在**世界区**（左上 900×600）内的鼠标操作有效；点在右侧面板上无效果。
- 粒子上限 `MAX_PARTICLES = 3000`。达到上限后再落水会被忽略，面板底部提示
  `已达粒子上限 3000`；该提示 2.5 秒后自动消失。
- 暂停时左键/右键仍可加液体、画固体，只是物理不推进。
- 右侧面板实时显示：粒子数、FPS、动能、约束迭代次数、运行/暂停状态，以及操作提示。
  若系统找不到可显示中文的字体，标签会自动切换到英文。

## 三、物理模型说明

### 3.1 表示

水体是 N 个**等质量**粒子（`UNIT_MASS = 1.0`），二维，位置 `(x, y)`、速度 `(vx, vy)`。
状态存放在并行的 float 列表里（结构体数组拆成数组结构体），便于热点循环逐元素访问。

### 3.2 核函数

支撑半径 `h = SMOOTHING_RADIUS = 30`。用两个核分工：

| 用途 | 核 | 公式（已二维归一化） |
|---|---|---|
| 密度求和、粘性权重 | poly6 | `W(r) = 4/(π h⁸) · (h² − r²)³`，`r ≥ h` 时为 0 |
| 约束梯度 | spiky（只取幅值） | `|∇W(r)| = 45/(π h⁶) · (h − r)²` |

### 3.3 静止密度 ρ0 的取法

`ρ0 = lattice_density(REST_SPACING)`：把粒子按间距 `REST_SPACING = 12` 摆成无限正方点阵，
把该点阵上所有 poly6 贡献加起来得到 **ρ0 ≈ 6.9026e-03**。

这样做而不是用连续近似 `1/spacing²`，是为了让"粒子按静止间距均匀排布"时
`C_i = ρ_i/ρ0 − 1` **严格等于 0**；否则近似带来的系统偏差会让整团水长期被判成"被压缩"，
液体会被持续推挤、永远静不下来。

### 3.4 每个 `step(dt)` 的执行顺序

```
1. 重力积分          v += g·dt（g = +y 方向 900 px/s²）
2. 位置预测          p* = p + v·dt
3. 重复 CONSTRAINT_ITERATIONS(=4) 次：
     3a. 密度约束求解（位置修正）
     3b. 位置投影（钳回世界矩形内 + 推出固体矩形外）
4. 由位置差反推速度  v = (p_new − p_prev) / dt
5. XSPH 粘性         v_i += VISCOSITY/ρ0 · Σ_j (v_j − v_i)·W(|p_i−p_j|)
6. 阻尼              v *= DAMPING(0.99)
7. 数值保护          速度截断到 MAX_SPEED、非有限值复位（正常情况不触发）
```

第 3 步把碰撞投影放进迭代循环里，是为了让"推开以缓解压缩"和"不许出界/进固体"
这两个约束互相收敛，而不是最后一步硬夹一次导致贴墙处密度偏高。

### 3.5 密度约束（本轮的核心）

对每个粒子统计邻域密度后：

```
ρ_i = Σ_j W(|p_i − p_j|) + W(0)        # 包含自身
C_i = max(0, ρ_i/ρ0 − 1)               # 只处理"压缩"，残差恒 ≥ 0
λ_i = −C_i / ( |Σ_j ∇W_ij / ρ0|² + ε )  # C_i = 0 时 λ_i = 0
Δp_i = (1/ρ0) · Σ_j (λ_i + λ_j) · ∇W_ij
```

（`ε = DENSITY_EPSILON = 1e-6`。）求得的 `Δp` 乘 `RELAXATION = 1.0` 后应用，
但单次迭代单粒子的位移被限制在 `MAX_CORRECTION_FACTOR × REST_SPACING = 0.25 × 12 = 3px`，
用于在初始重叠（例如刚落下的整团粒子）时压制数值爆炸。

只对 `C > 0` 求解意味着约束是**单边**的：压缩会推开，拉伸不产生吸引。这一点见「已知限制」。

### 3.6 邻域搜索

均匀空间网格，格子边长取 `CELL_SIZE = h = 30`，查询时遍历 3×3 个格子即可覆盖半径 h 内的全部邻居，
整体复杂度约 **O(n)**，而不是 O(n²)。每个子步、每次约束迭代各重建一次邻居对列表。

### 3.7 碰撞

采用**位置投影**，不改速度：

- 世界墙：粒子中心被钳在 `[margin, width − margin] × [margin, height − margin]`，
  `margin = COLLISION_MARGIN = 6`（等于粒子半径）。
- 固体：若中心落在矩形内部，取到四条边距离最近的一条，沿该方向推到矩形外 `margin` 处；
  推开后再夹一次世界墙（应对紧贴墙壁的固体）。

由于速度是第 4 步由位置差反推的，撞墙后法向分量被约束"吃掉"，粒子自然贴着墙滑落，
不需要额外写"把法向速度归零/反弹"。

### 3.8 粘性（XSPH）

`v_i += (VISCOSITY/ρ0) · Σ_j (v_j − v_i) · W_ij`。

它只按核权重拉平**相对速度**（相邻粒子趋向同速），不改变质心速度，更不是"每步把速度乘 0"。
没有它，位置约束的残差会以高频抖动长期驻留在能量里，液体看起来永远在沸腾。

### 3.9 固定步长与累加器

物理步长固定 `PHYSICS_DT = 1/60` 秒，与渲染帧率解耦（累加器）：

- 帧率高不加速、帧率低不减速；
- 单帧最多补 `MAX_SUBSTEPS = 3` 个子步；
- 补到上限仍欠时间，则**丢弃积压**，宁可物理比真实时间慢一点，也不"追帧爆炸"；
- 单帧时间还被 `MAX_FRAME_DT = 0.25` 秒夹住，`step` 内部再用 `MAX_DT = 1/30` 挡一次异常大的 dt。

### 3.10 质量守恒

粒子只在 `add_water` / `clear_water` 时增减；`step()` 从不增删粒子，只移动粒子。
因此 `total_mass = count × UNIT_MASS` 在推进过程中严格不变，可直接作为守恒的观测值。

## 四、参数说明

数值全部集中在 `config.py`（`core.py` / `main.py` 只读，不另设魔数）。

### 4.1 世界与窗口

| 参数 | 默认值 | 含义与调节建议 |
|---|---|---|
| `WORLD_WIDTH` | 900 | 世界宽（像素）。改大后同样粒子数下液面更薄 |
| `WORLD_HEIGHT` | 600 | 世界高（像素） |
| `PANEL_WIDTH` | 220 | 右侧信息面板宽；窗口总宽 = 两者之和 |
| `FPS` | 60 | 渲染目标帧率（`clock.tick` 的上限），不决定物理步长 |
| `PHYSICS_DT` | 1/60 | 固定物理步长（秒）。改小更稳但更耗 CPU |
| `MAX_SUBSTEPS` | 3 | 单帧最多补几个物理子步，超过则丢弃积压 |
| `MAX_PARTICLES` | 3000 | 粒子上限，超出时 `add_water` 返回实际添加数（可能为 0） |

### 4.2 粒子与核函数

| 参数 | 默认值 | 含义与调节建议 |
|---|---|---|
| `PARTICLE_RADIUS` | 6.0 | 粒子名义半径（像素），决定渲染贴图与碰撞 margin |
| `REST_SPACING` | 12.0 | `= 2 × PARTICLE_RADIUS`，静止时粒子中心距，也是 ρ0 的点阵间距 |
| `SMOOTHING_RADIUS` | 30.0 | `= 2.5 × REST_SPACING`，核函数支撑半径 h。h/间距越小，邻域粒子越少、越脆 |
| `CELL_SIZE` | 30.0 | `= h`，空间网格边长，保证 3×3 邻域覆盖全部邻居 |
| `UNIT_MASS` | 1.0 | 单粒子质量，仅用于质量守恒观测 |

### 4.3 密度约束

| 参数 | 默认值 | 含义与调节建议 |
|---|---|---|
| `CONSTRAINT_ITERATIONS` | 4 | 每步密度约束迭代次数（规范要求 ≥ 3）。调大更硬、更不可压，但更慢 |
| `RELAXATION` | 1.0 | 每次迭代位置修正的松弛系数，1.0 = 全量修正；<1 更柔、收敛更慢 |
| `MAX_CORRECTION_FACTOR` | 0.25 | 单次迭代单粒子位移上限 = 该系数 × `REST_SPACING` = 3px，防初始重叠爆炸 |
| `DENSITY_EPSILON` | 1e-6 | λ 分母的数值保护项，避免粒子恰好重合时除零 |

### 4.4 外力与时间积分

| 参数 | 默认值 | 含义与调节建议 |
|---|---|---|
| `GRAVITY` | 900.0 | 重力加速度（px/s²），方向 +y。调大水流更急，对迭代次数要求更高 |
| `DAMPING` | 0.99 | 每步速度阻尼系数（保留惯性）。1.0 = 无阻尼，液体难静；过小则"像糖浆" |
| `MAX_DT` | 1/30 | 单个 `step` 允许的最大 dt，防御异常大输入 |
| `MAX_SPEED` | 6000.0 | 速度上限（px/s），只在数值保护里使用，不参与正常演化 |
| `VISCOSITY` | 0.10 | XSPH 粘性系数：只耗散粒子间**相对**速度，压掉约束抖动；调大更粘、更像糖浆 |

### 4.5 碰撞

| 参数 | 默认值 | 含义与调节建议 |
|---|---|---|
| `COLLISION_MARGIN` | 6.0 | `= PARTICLE_RADIUS`，粒子中心与墙/固体面至少保持的距离；世界过小时会自动收缩到半宽/半高以内 |

### 4.6 默认场景与界面常量

| 参数 / 常量 | 位置 | 默认值 | 含义 |
|---|---|---|---|
| `DEFAULT_SPAWN_RADIUS` | `config.py` | 24.0 | 左键单次落水的画刷半径 |
| `DEFAULT_SPAWN_COUNT` | `config.py` | 6 | 左键单次落水的粒子数 |
| `COLOR_*` | `config.py` | — | 背景、水、水边、固体、固体边、文字、面板配色 |
| `SPAWN_INTERVAL` | `main.py` | 0.035 秒 | 左键按住时的落水间隔（按时间而非帧计） |
| `MAX_FRAME_DT` | `main.py` | 0.25 秒 | 单帧时间上限，断点/拖窗口后不让物理一口气补太多 |
| `PANEL_PAD` / `MIN_DRAG_SIZE` | `main.py` | 14 / 4.0 | 面板内边距 / 小于该尺寸的拖拽矩形被忽略 |

默认场景（`build_default_scene`）：`(0.10w, 0.66h, 0.26w, 14)`、`(0.52w, 0.48h, 0.24w, 14)`
两块台阶，`(0.06w, 0.92h, 0.88w, 16)` 底部托盘，外加 `(0.42w, 0.16h)` 半径 46 的 420 粒
与 `(0.78w, 0.10h)` 半径 30 的 200 粒两团水。

## 五、已知限制

1. **二维**。所有约束、核函数归一化、邻域搜索都是二维形式，结果不能直接外推到三维。
2. **无表面张力**。没有表面张力约束，水体不会自发收缩成水滴/珠状；飞溅、薄膜等表面主导的现象不会出现，水只会摊开。
3. **单边密度约束**。`C_i = max(0, ρ/ρ0 − 1)` 只处理压缩、拉伸时无吸引，所以水体被拉开后不会"回聚"，
   剧烈飞溅后可能出现短暂的稀疏空洞/断裂。
4. **粘性只是扩散近似**。XSPH 是按核权重拉平相对速度的数值粘性，没有真实黏度系数与雷诺数含义，
   调 `VISCOSITY` 得到的是手感而不是物理量。
5. **无相变、无热力学、无多相**。不支持气体/泡沫/泥沙、温度、浮力、密度分层；
   所有粒子质量恒为 1.0，不能做重粒子或多流体。
6. **固体是静态轴对齐矩形**。不能移动、旋转、被水推动；没有摩擦系数与恢复系数，
   碰撞是"硬"的位置投影，贴壁滑动不做速度衰减。
7. **潜在穿透（隧穿）**。位置投影把粒子推出**最近的**固体面；如果单步位移超过固体厚度，
   粒子可能已被推过另一侧。`MAX_DT = 1/30`、`MAX_SPEED = 6000` 下极端情况（极高速度 + 很薄的板）仍可能出现。
8. **纯 Python 性能上限**。粒子数接近 3000 时，每个子步要重建 4 次邻居对，帧率可能下降；
   卡顿时会按 `MAX_SUBSTEPS` 丢积压时间——**物理会比真实时间慢**（不追帧），这是有意取舍。
9. **参数手调**。没有 CFL 条件或自适应步长：`GRAVITY` 调大、`CONSTRAINT_ITERATIONS` 调小、
   `DAMPING` 接近 1 三者叠加时，会出现可见的压缩、抖动或"沸腾感"。同时增大重力就需要更多迭代。
10. **静置后仍会有轻微残差**。XSPH + 阻尼可以把高频抖动压下去（动能单调下降），但不保证严格为 0。
11. **无持久化**。没有场景保存/读取、录制/回放、截图导出；关闭窗口后场景即丢失。
12. **字体依赖**。找不到中文字体时面板自动改用英文标签；无头模式（`--headless`）不显示任何画面，只能看退出摘要。
