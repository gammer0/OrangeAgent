# 生命周期

> 返回 [总览](README.md)

---

| 结构 | 创建 | 销毁 |
|------|------|------|
| `Session` / `SessionRegistry` / `EvictionPolicy` | 实例化时 / 进程启动 | 显式结束或进程结束 |
| `SessionRecord` | 会话创建 | 持久化，不删除 |
| `SystemMsg` | 会话开始 | 会话结束 |
| `Inbox` / `UserInput` / `InterruptRequest` | 会话创建 | 会话结束（元素级即时消费） |
| `UserMsg` / `AssistantMsg` / `ToolMsg` | 运行中逐条追加 | 会话结束 |
| `FlatStore` / `ToolTree` | 启动时挂载并建树 | 进程结束 |
| `TreeQueryState` | 会话开始 | 会话结束；上下文压缩时清空 `delivered` |
| `DiscoveredTools` | 首次树查询 | 会话结束；上下文压缩时清空 |
| `ProjectMemory` / `MemoryEntry` | 首次结算 | 持久化，只追加 |
| `MemoryExtraction` | 用户触发结算 | 提取完成后 |
| `BatchPlan` / `ExecGroup` / `ExecResult` | 每批次 | 全批结果回填后 |
| `TraceEvent` | 每步 | 持久化（一会话一文件） |
| `Watermark` | 会话开始 | 会话结束 |
| `RateWindow` / `ProviderHealth` | 进程启动 | 进程结束 |
| `usage` 表记录 | 每次 LLM 调用 | 持久化，不删除 |

---

## 持久化落点

| 数据 | 存储 | 位置 |
|------|------|------|
| 会话元信息 | SQLite `sessions` | `<workdir>/.agent/harness.db` |
| 消息历史 | SQLite `messages` | 同上 |
| 用量与成本 | SQLite `usage` | 同上 |
| 工作记忆 | Markdown | `<workdir>/.agent/WORK.md` |
| 长期记忆 | Markdown | `<global>/.agent/MEMORY.md` |
| 提取原则 | Markdown | `<global>/.agent/extract.md` |
| 轨迹 | JSONL | 每会话一个文件 |
