## 2. 一次 ReAct 步的完整数据流

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户界面
    participant IB as Inbox
    participant L as AgentLoop
    participant C as ContextAssembler
    participant DB as SQLite
    participant P as ReverseProxy
    participant R as Provider
    participant S as BatchScheduler
    participant X as Executor
    participant T as ToolTree
    participant M as WORK.md

    Note over L: 安全点①：drain chat → UserMsg
    IB-->>L: UserInput[] （chat）
    L->>DB: INSERT user 消息
    L->>C: assemble()
    C->>C: SystemMsg 五段 + Message 家族
    C->>C: validate_messages
    C->>C: to_provider + 末尾注入 DiscoveredTools
    C->>P: chat(messages)
    P->>R: HTTP
    R-->>P: content + tool_calls
    P-->>L: AssistantMsg
    L->>DB: INSERT assistant

    opt 有 tool_calls
        L->>T: 路径 → ToolNode → tool_id
        T->>T: DAC 权限判定
        alt abstract 节点
            T->>T: tree_query → TreeQueryState + DiscoveredTools
        end
        L->>S: 生成 BatchPlan / ExecGroup
        loop 每个 ExecGroup
            S->>X: 组内调用
            X->>M: 读写工作记忆（若命中）
            X-->>L: ExecResult[]
            L->>DB: INSERT tool 消息（同事务）
            Note over L,IB: 安全点②：只 drain control
            IB-->>L: InterruptRequest?
        end
        Note over L: 安全点③：drain chat + control
    end
```

## 5. 持久化落点总表

| 结构 | 存储介质 | 位置 | 生命周期 |
|------|---------|------|---------|
| `Session` 元信息 | SQLite `sessions` | `<workdir>/.agent/orange.db` | 永久 |
| `UserMsg` / `AssistantMsg` / `ToolMsg` | SQLite `messages` | 同上 | 永久 |
| 用量与成本 | SQLite `usage` | 同上 | 永久 |
| 工作记忆 | Markdown | `<workdir>/WORK.md` | 跨会话 |
| 长期记忆 | Markdown | `<global>/.agent/MEMORY.md` | 跨项目 |
| 提取原则 | Markdown | `<global>/.agent/extract.md` | 用户维护 |
| 轨迹 | JSONL | 一会话一文件 | 追加 |
| `FlatStore` | 内存（代码注册或配置加载） | — | 进程级；条目可标记 `retired` |
| `ToolTree` | 内存 | — | 进程级；由 `FlatStore` 派生，可全量重建 |
| `TreeQueryState` / `DiscoveredTools` | 内存 | — | 会话级，压缩清空 |
| `BatchPlan` / `ExecResult` | 内存 | — | 批次级 |
| `RateWindow` / `ProviderHealth` | 内存 | — | 进程级 |

## 6. 跨层不变量在数据流上的体现

| 不变量 | 在流中的位置 | 守护点 |
|--------|-------------|--------|
| `messages[0]` 逐字节稳定 | 每次 `to_provider` 之前 | `SystemMsg` 五段装配一次，之后只读 |
| 每个 `tool_call` 有配对 `tool` | 每轮 LLM 调用前 | `validate_messages`（A3） |
| 权限不足节点不可见 | `tree_query` 与树索引 | DAC 在查询时过滤 |
| 优化失败无损退化 | 路由、并发分组 | 低置信回退全量 |
| `3d` 不重复计数 | 参数校验 | 并入死锁判据 |
| 中断不产生半截历史 | 安全点提交 | 组级事务 + 补 3e |
| `UserMsg` 不插入未闭合序列 | 安全点 ② | `chat` 不出队 |
