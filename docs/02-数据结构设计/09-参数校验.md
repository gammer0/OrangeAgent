# 参数校验与 `3d`

> 返回 [总览](README.md)

`ToolCall.arguments` 是原始 JSON 字符串，执行前经四道关卡，任一失败归 `3d ArgumentMismatch`。

---

## 9.1 四道关卡

| 关 | 动作 | 失败示例 |
|----|------|---------|
| ① | JSON 解析 | 截断、多逗号 |
| ② | Schema 校验 | 缺必填字段、类型不符、枚举非法 |
| ③ | 类型转换与缺省填充 | 数字字符串转 `int` 失败 |
| ④ | 调用 `fn` | 函数内部参数错误，归 `3c` 而非 `3d` |

## 9.2 回填内容

`3d` 的 `ExecResult.content` 为序列化 JSON，必须包含**可自我修正**的信息：

```json
{
  "stage": "schema",
  "errors": [
    {"field": "path",   "kind": "missing",  "expected": "string"},
    {"field": "offset", "kind": "type",     "expected": "integer", "actual": "string"},
    {"field": "mode",   "kind": "enum",     "allowed": ["safe", "exclusive"]}
  ]
}
```

| 失败类型 | 回填字段 |
|---------|---------|
| JSON 解析 | `stage: "parse"` + 原始字符串 + 错误位置 |
| 缺字段 | `kind: "missing"` + `field` + `expected` |
| 类型不符 | `kind: "type"` + `field` + `expected` + `actual` |
| 枚举非法 | `kind: "enum"` + `field` + `allowed` |
| 多余字段 | 允许并忽略，仅记轨迹，不报 `3d` |

## 9.3 重试规则

`3d` **不自动重试**——工具从未执行，重试意味着让模型重新生成参数。

| 项 | 规则 |
|----|------|
| 触发方式 | 回填 `ToolMsg` 后进入下一轮 LLM，由模型自行修正 |
| 上限 | 不单独计数，由死锁判据统一处理（连续 3 次失败且结果 hash 未变且未换工具路径） |
| 修复策略 | **不自动修复** JSON；原样回填，让模型看到真实错误 |

## 9.4 约束

| # | 约束 |
|---|------|
| J1 | `arguments` 不得被自动修复或补全，只能原样解析 |
| J2 | `3d` 的 `content` 必须是合法 JSON，含 `stage` 与 `errors` |
| J3 | 多余字段允许忽略，但必须写入 `TraceEvent` |
| J4 | `3d` 不单独计数重试，由死锁判据统一判定终止 |
