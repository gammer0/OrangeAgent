# 记忆（C 组）

> 返回 [总览](README.md)

记忆以**文件**为存储单位，不是内存对象。工作记忆为自由文本，无结构。

> 工作记忆是**项目级**的，位于工作目录内；长期记忆与提取原则是**全系统唯一**的，
> 位于数据目录 `~/.orange`（可用 `ORANGE_HOME` 覆盖）。

---

## 5.1 文件布局

| 文件 | 数量 | 位置 |
|------|------|------|
| 工作记忆 | **每个工作目录一份** | `<workdir>/WORK.md` |
| 长期记忆 | **全系统唯一** | `~/.orange/MEMORY.md` |
| 提取原则 | **全系统唯一** | `~/.orange/extract.md` |

```
<workdir>/
└── WORK.md              工作记忆（同工作目录的多会话共享，不建子目录）

~/.orange/
├── MEMORY.md            长期记忆（全系统唯一）
└── extract.md           提取原则（全系统唯一，用户编写）
```

| 文件 | 性质 | 写入方 | 读取方 |
|------|------|--------|--------|
| `WORK.md` | 工作记忆，自由 Markdown | agent 通过文件工具读写 | agent、结算提取程序 |
| `MEMORY.md` | 长期记忆，跨会话与跨项目累积 | **仅**后台提取程序 | `SystemMsg` 第 3 段只列文件名 |
| `extract.md` | 提取原则 | 用户 | 后台提取程序 |

## 5.2 长期记忆格式

```
ProjectMemory
├── entries: list[MemoryEntry]
└── updated_at: float

MemoryEntry
├── text: str                          一条**跨项目通用**结论
├── source_workdir: str                来源工作目录，仅用于溯源
└── updated_at: float
```

长期记忆是**持续累积**的：每次结算向 `entries` 追加/合并，不整体覆盖。

**只存通用结论**：项目专属内容留在该项目的 `WORK.md`，不进入长期记忆。这一点由提取原则控制（C8），而不是靠读取时过滤。

## 5.3 结算提取

`MemoryExtraction` 是用户显式触发的后台任务，**不阻塞主循环**。

```
MemoryExtraction
├── source_path: str                   <workdir>/WORK.md
├── principle_path: str                ~/.orange/extract.md
├── target_path: str                   ~/.orange/MEMORY.md
└── status: "pending" | "running" | "done" | "failed"
```

| 阶段 | 行为 |
|------|------|
| 触发 | 用户下发结算控制指令 |
| 中断 | 通过 `control` 通道中断当前批次 |
| 提取 | 后台 LLM 按提取原则读工作记忆，产出 `MemoryEntry` |
| 写入 | 追加合并到全系统唯一的长期记忆文件 |

## 5.4 约束

| # | 约束 |
|---|------|
| C1 | 工作记忆为自由文本，系统不解析其结构 |
| C2 | 工作记忆正文**不进** `SystemMsg`；`messages[0]` 只说明读写模式与路径 |
| C3 | 长期记忆只由后台提取程序写入，agent 不可直接写 |
| C4 | 同一工作目录下仅一个 `WORK.md`，多会话共享；写入必须原子（临时文件 + 重命名） || C5 | 结算提取在独立线程运行，失败不得影响主循环 |
| C6 | `MemoryEntry.source_workdir` 仅用于溯源，不注入模型上下文 |
| C7 | 长期记忆与提取原则全系统各仅一份，不随工作目录变化；多工作目录的结算共享同一个 `entries` |
| C8 | 长期记忆只收录跨项目通用结论；阅读时不按来源过滤，项目专属内容由提取原则排除 |
