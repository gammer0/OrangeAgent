# 模型层运行时（K 组）

> 返回 [总览](README.md)

多会话共享同一个 `ReverseProxy`，因此限流、成本、退避均为**全局状态**。

---

## 10.1 `RateWindow`

滑动窗口限速。

```
RateWindow                            全局
├── window_s: int = 60
├── max_requests: int
├── max_tokens: int
└── events: Deque[RateEvent]          窗口内事件，按 ts 升序

RateEvent
├── ts: float
├── session_id: str
├── tokens: int                        请求前估算
└── actual_tokens: int | None          响应后回填
```

## 10.2 `ProviderHealth`

退避与故障转移是**全局信号**，不是每会话独立。

```
ProviderHealth                        全局
├── provider: str
├── state: "healthy" | "degraded" | "down"
├── consecutive_failures: int
├── retry_after: float                 全局退避截止时间
└── switched_to: str | None            故障转移目标
```

| 状态 | 发送行为 |
|------|---------|
| `healthy` | 正常发送 |
| `degraded` | 发送前等待 `retry_after` |
| `down` | 直接失败，不重试 |

## 10.3 成本归集

写入 SQLite，与 `sessions` / `messages` 同库。

```sql
CREATE TABLE usage (
    session_id   TEXT NOT NULL,
    step         INTEGER NOT NULL,
    model        TEXT NOT NULL,
    tokens_in    INTEGER NOT NULL,
    tokens_out   INTEGER NOT NULL,
    cost_usd     REAL NOT NULL,
    created_at   REAL NOT NULL,
    PRIMARY KEY (session_id, step)
);
```

## 10.4 约束

| # | 约束 |
|---|------|
| K1 | 限流只做全局并发与速率窗口；不做每会话并发限制（ReAct 串行，恒为 1） |
| K2 | 每个 `RateEvent` 必须携带 `session_id` |
| K3 | `RateWindow` 淘汰只按 `ts` 滑出窗口，不按会话 |
| K4 | `ProviderHealth` 为全局单例；退避与故障转移对所有会话生效 |
| K5 | `ProviderHealth.state != "healthy"` 期间的请求不计入 `consecutive_failures` 重复累加 |
| K6 | 每次 LLM 调用结束必须写入一条 `usage` 记录，主键 `(session_id, step)` |
| K7 | `usage.cost_usd` 按 provider 单价与 `tokens_in` / `tokens_out` 计算 |
