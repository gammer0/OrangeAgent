## 6.1 字段定义

```
BatchPlan
├── calls: list[ToolCall]               本批全部调用，顺序 = provider 返回顺序
├── groups: list[ExecGroup]             子批次序列，groups 拼接 == calls
├── mode: "serial" | "parallel"        整个批次的执行模式
└── results: dict[str, ExecResult]      key = tool_call_id

ExecGroup                            子批次：一次可提交的原子单位
├── index: int                         在本批中的序号，从 0 起
├── calls: list[ToolCall]              组内调用，有序
└── mode: "serial" | "parallel"        组内执行模式

ExecResult
├── ok: bool
├── content: str                        已序列化（JSON 或文本）
├── error_type: str | None              "1" | "2" | "3a" | "3b" | "3c" | "3d" | "3e"
├── retryable: bool                     按 ToolDef.idempotent 推导
└── duration_ms: int
```

## 6.2 分组规则

分组由 `BatchScheduler` 在查询后、执行前一次性产出，执行期间不可变。

| 输入 | 分组结果 |
|------|---------|
| 全部 `safe` | 单个 `parallel` 组，含全部调用 |
| 连续 `safe` + 离散 `exclusive` | 每个 `exclusive` 独占一组；相邻 `safe` 合并为一组（不跨 `exclusive`） |
| 出现任一 `exclusive` | `BatchPlan.mode = "serial"`，各组的 `mode` 各自判定 |

`safe` 组可并行；`exclusive` 组内部单元素，天然串行。

## 6.3 子批次安全点

每个 `ExecGroup` 执行完毕并回填 `ToolMsg` 后即为一个安全点，共 `1 + len(groups)` 个安全点（1 为 LLM 返回后）。消费哪些队列见 [接入层 §1.5](01-接入层.md)。

| 安全点位置 | `chat`（等待插入） | `control`（立即插入） |
|-----------|------------------|---------------------|
| LLM 返回后（①） | 允许，全部 drain | 允许（此时无未闭合调用） |
| 某个组完成、仍有后续组（②） | **禁止**（消息留队列） | 允许：停止剩余组，为本批全部未回填调用补 `3e` |
| 全部组完成（③） | 允许，全部 drain | 允许（天然闭合） |
| 组内执行过程中 | 禁止 | 禁止（留半截状态） |

补占位的 `ToolMsg` 固定值：

```
error_type = "3e"
ok         = false
retryable  = false
content    = {"status": "skipped", "reason": "<InterruptRequest.reason>"}
```

`content.reason` 取自触发中断的 `InterruptRequest.reason`（`user_abort` / `session_end` / `timeout`），不得写死。`3e` 语义是“未执行”而非“执行失败”，不得触发退避重试。

## 6.4 约束

| # | 约束 |
|---|------|
| D1 | `mode == "parallel"` 当且仅当所有 `ToolDef.concurrency == "safe"` |
| D2 | `results` 的键必须与 `calls[].id` 一一对应 |
| D3 | 回填 `ToolMsg` 时按 `groups` 顺序、组内按 `calls` 顺序遍历，不按完成顺序 |
| D4 | `ok == False` 时 `content` 仍必须是合法字符串（错误描述） |
| D5 | `groups` 按序拼接后必须与 `calls` 完全一致（无遗漏、无重复、无重排） |
| D6 | 组内 `parallel` 时 `mode == "parallel"`，且组内元素全部 `concurrency == "safe"` |
| D7 | 立即插入停止剩余组时，必须覆盖本批全部未回填调用补占位，不得只补未执行部分；`error_type == "3e"` 时 `retryable` 必须为 `false` |
| D8 | 未闭合 `tool_calls` 序列内部不得插入 `UserMsg`（见不变量 I6） |
