# Web 控制台使用手册

> 启动：`uv run uvicorn apps.server.main:app --port 8012 --host 127.0.0.1`
> 地址：<http://127.0.0.1:8012>

---

## 1. 界面一览

```
┌──────────────────────────────────────────────────────────────┐
│ Harness  ● 10 个会话 · 18 个工具      模型 ▾   设置   新建会话 │
├──────────┬────────────────────────────────┬──────────────────┤
│          │                                │  轨迹 │ 上下文   │
│ 会话列表 │          对话区                │ ──────────────── │
│          │                                │  水位进度条      │
│  22ef…   │   你：读取 pyproject.toml      │  工具调用记录    │
│  8cd2…   │   AI：前 3 行是…               │  下钻过程        │
│          │                                │                  │
├──────────┴────────────────────────────────┤                  │
│ [ 输入消息… ]                     发送 中止 │                  │
└────────────────────────────────────────────┴──────────────────┘
```

| 区域 | 作用 |
|---|---|
| **顶栏** | 服务状态灯、会话与工具计数、模型选择、设置入口、新建会话 |
| **左栏** | 会话列表，点击切换；悬停出现删除按钮 |
| **中间** | 对话本体。**只显示对话**，工具调用不在这里 |
| **右栏** | 轨迹（工具调用 + 树状下钻）与上下文（模型实际看到的消息） |
| **底部** | 输入框、发送/中止按钮 |

## 2. 基本操作

### 新建会话

点右上角「新建会话」。顶部下拉框选中的模型决定新会话使用哪个模型。

### 发送消息

| 操作 | 结果 |
|---|---|
| `Enter` | 换行 |
| `Ctrl`+`Enter` | 发送（等当前步结束后插入） |
| `Ctrl`+`Shift`+`Enter` | 立即插入（不等当前步结束） |

**两者的区别**：普通发送会在安全点排队；立即插入会打断当前推理，适合「别再试了，换个方向」。

### 中止

推理进行中点「中止」。会在下一个安全点停下，已产生的工具结果会保留。

### 删除会话

鼠标悬停在会话列表项上，点右侧 `×`。删除不可撤销，会同时清掉消息与轨迹。

## 3. 看懂对话区

- **流式输出**：模型生成时文字逐字出现，带闪烁光标与 `streaming` 标签。
- **结束标签**：回复完成后显示 `final` 与时间。
- **工具调用不显示在对话里**——这是刻意的。对话只保留「人话」，工具执行细节全在右侧轨迹。

---

## 4. 看懂轨迹面板

轨迹记录**发生了什么**，按时间倒序（最新在最上）。

### 事件类型

| 标签 | 含义 |
|---|---|
| `TOOL` | 工具调用。显示路径、参数（橙色左边框）、返回内容 |
| `ASSISTANT` | 模型的一次回复 |
| `ROUTE` | 路由判定（选分支或回退全量） |
| `USAGE` | 当时上下文水位 |
| `STATE` | 会话状态变化 |
| `COMPRESS` | 上下文压缩触发 |
| `ERROR` | 出错 |

### 树状下钻是什么

这个平台的工具按树组织。模型先看到 `/tool`，再逐级展开：

```
/tool              ← 资源根
/tool/os           ← 展开一层
/tool/os/file      ← 再展开
/tool/os/file/read ← 具体工具，真正执行
```

轨迹面板会完整记录这条路径。**对话历史里看不到它们**——一旦模型选到具体工具，这些探索记录就会从上下文里移除（工具本身已缓存，留着只是浪费 token）。

因此轨迹是**唯一能看到「模型是怎么找到这个工具的」的地方**，并且会持久化，重启后仍可回看。

### 上下文水位

进度条显示 `已用 token / 容量`：

| 区间 | 含义 |
|---|---|
| < 50% | 正常 |
| ≥ 50% | 触发一级压缩（保留最近 4 条调用记录） |
| ≥ 75% | 触发二级压缩（保留 2 条） |
| ≥ 85% | 不再压缩，本轮结束并建议开新会话 |

## 5. 看懂上下文面板

这里列出模型**实际看到的消息**，与对话区的区别是：

- 包含工具返回内容（`tool` 行）
- 不含系统提示词（太长，且不是对话的一部分）

用来回答「模型到底知道什么」。觉得模型「忘事」或「记错了」，先看这里。

## 6. 设置界面

点顶栏「设置」。

### 能改什么

40 项超参数，分 7 组：

| 组 | 典型项 |
|---|---|
| `context` | 上下文容量、压缩水位、单次工具输出上限 |
| `loop` | 最大步数、最大插话次数、死锁阈值 |
| `execution` | 并发线程数 |
| `tools` | 索引深度、发现缓存上限 |
| `sessions` | 驻留会话数、空闲超时 |
| `rate` | 限流窗口、熔断阈值 |
| `memory` | 记忆文件名、替换重试 |

### 改完什么时候生效

| 标记 | 含义 |
|---|---|
| 无标记 | **立即生效**，下一条消息就用新值（如 `max_steps`） |
| `重启生效` | 需要重启服务（如 `capacity`、并发数、限流参数） |

保存时界面会明确列出哪些项需要重启，不会假装已经生效。

### 恢复默认

- 单项：鼠标悬停在该行，点右侧「恢复」
- 全部：点底部「全部恢复默认」

### 存到哪

`~/.OAgent/settings.json`，只记录**与默认值不同**的项。优先级高于 `.env`。

| 颜色 | 含义 |
|---|---|
| 绿色 | 空闲，服务正常 |
| 橙色（呼吸） | 正在推理 |
| 红色 | 无法连接服务 |

## 9. 常见问题

**界面一直显示「连接中…」**
服务没起来，或端口不是 8012。检查终端里 uvicorn 是否在跑。

**回复一次性全部出现，没有逐字效果**
说明该模型的 provider 不支持流式，系统会自动退回整体返回。功能不受影响。

**某次回复卡住不动**
单轮若无任何进展超过 5 分钟，看门狗会放弃该轮并提示超时。会话仍可继续使用，不必重启。

**删除会话后列表没变**
列表在状态变化时刷新，下拉刷新页面即可。

**改了设置但没变化**
看保存提示：标「重启生效」的项必须重启服务。

**轨迹面板是空的**
两种情况：新会话还没产生事件；或该会话是老数据、其轨迹未落盘。发出第一条消息后就会有。
